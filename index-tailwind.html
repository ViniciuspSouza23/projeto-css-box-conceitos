⚡ Demonstrações Práticas de Flexbox com Tailwind CSS

Exemplos visuais e dinâmicos controlados exclusivamente pelas classes utilitárias de Flexbox: flex, justify-*, items-*, grow e self-*.

1. Distribuição: justify-between & flex-wrap

flex flex-row flex-wrap justify-between items-center gap-4
Item A grow (flex-grow: 1)
Item B grow-[2] (flex-grow: 2)
Item C -order-1 (order: -1)
Item D self-end (align-self: flex-end)

2. Fluxo Vertical: flex-col & items-center

flex flex-col justify-center items-center gap-3.5
Item Superior self-start (align-self: flex-start)
Item Central self-center (align-self: center)
Item Inferior self-end (align-self: flex-end)

📋 Dicionário: CSS Nativo ➔ Classes Tailwind CSS

Guia de equivalência das 24 propriedades de Flexbox utilizadas no projeto com suas respectivas classes utilitárias no Tailwind:

#01 flex
display: flex;

Torna o contêiner flexível de bloco.

#02 inline-flex
display: inline-flex;

Cria um contêiner flexível com comportamento inline.

#03 flex-row
flex-direction: row;

Organiza os itens na horizontal da esquerda para a direita.

#04 flex-col
flex-direction: column;

Organiza os itens no eixo vertical de cima para baixo.

#05 flex-row-reverse
flex-direction: row-reverse;

Inverte o sentido horizontal dos elementos flexíveis.

#06 flex-col-reverse
flex-direction: column-reverse;

Inverte o sentido vertical dos elementos flexíveis.

#07 flex-wrap
flex-wrap: wrap;

Permite a quebra dos elementos em várias linhas.

#08 flex-nowrap
flex-wrap: nowrap;

Mantém todos os elementos sempre na mesma linha.

#09 flex-wrap-reverse
flex-wrap: wrap-reverse;

Quebra as linhas adicionais no sentido invertido.

#10 flex-row flex-wrap
flex-flow: row wrap;

Combinação simultânea de direção horizontal e quebra.

#11 justify-center
justify-content: center;

Centraliza os itens ao longo do eixo principal.

#12 justify-between
justify-content: space-between;

Espalha itens uniformemente; extremidades tocam as bordas.

#13 justify-around
justify-content: space-around;

Distribui itens com espaço igual ao redor de cada um.

#14 justify-evenly
justify-content: space-evenly;

Espaçamento estritamente igual entre itens e bordas.

#15 items-center
align-items: center;

Alinha itens no centro do eixo transversal/cruzado.

#16 items-stretch
align-items: stretch;

Estica os itens para preencher toda a altura transversal.

#17 content-between
align-content: space-between;

Distribui as linhas flexíveis quando há quebra.

#18 gap-6
gap: 24px; (row & col)

Espaçamento nativo e limpo entre colunas e linhas flex.

#19 order-1 / -order-1
order: 1; / order: -1;

Modifica a ordem de exibição visual de um filho específico.

#20 grow
flex-grow: 1;

Permite que o elemento cresça para ocupar espaço restante.

#21 shrink-0
flex-shrink: 0;

Impede o encolhimento do item quando o contêiner aperta.

#22 basis-[75px]
flex-basis: 75px;

Define a dimensão base inicial antes de crescer ou encolher.

#23 flex-1 / flex-initial
flex: 1 1 auto;

Shorthand combinando flex-grow, flex-shrink e flex-basis.

#24 self-end / self-start
align-self: flex-end;

Sobrescreve o alinhamento de um item filho individualmente.
