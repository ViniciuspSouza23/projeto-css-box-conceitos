📋 20 Propriedades do Flexbox Aplicadas

Referência didática de todas as 20 propriedades e valores de Flexbox implementados no projeto para controle responsivo:

#01 display: flex;

Define o elemento como um contêiner flexível de bloco.

#02 display: inline-flex;

Cria um contêiner flexível que se comporta inline no fluxo do texto.

#03 flex-direction: row;

Organiza os itens no eixo principal horizontal da esquerda para a direita.

#04 flex-direction: column;

Organiza os itens no eixo vertical de cima para baixo.

#05 flex-direction: row-reverse;

Inverte o sentido horizontal dos elementos flexíveis.

#06 flex-direction: column-reverse;

Inverte a ordem vertical dos elementos filhos.

#07 flex-wrap: wrap;

Permite que os itens quebrem linha quando não couberem na mesma fileira.

#08 flex-wrap: nowrap;

Força todos os itens flexíveis a permanecerem na mesma linha.

#09 flex-wrap: wrap-reverse;

Quebra os itens para linhas adicionais no sentido inverso.

#10 flex-flow: row wrap;

Atalho (shorthand) combinando flex-direction e flex-wrap.

#11 justify-content: center;

Centraliza os itens ao longo do eixo principal.

#12 justify-content: space-between;

Distribui itens com espaçamento uniforme; o primeiro e último nas bordas.

#13 justify-content: space-around;

Distribui itens com espaço igual ao redor de cada um deles.

#14 justify-content: space-evenly;

Distribui itens de modo que todos os espaços intermediários e bordas sejam iguais.

#15 align-items: center;

Alinha os itens no centro do eixo cruzado (perpendicular).

#16 align-items: stretch;

Estica os itens para preencher toda a altura/largura do contêiner.

#17 align-content: space-between;

Controla o alinhamento das linhas flexíveis em contêineres com quebra de linha.

#18 gap: 24px;

Define o espaçamento entre colunas e linhas sem necessidade de margins manuais.

#19 order: 1;

Modifica a sequência de exibição visual de um item flex específico.

#20 flex-grow: 1;

Define a capacidade de um item crescer para preencher o espaço restante disponível.

#21 flex-shrink: 0;

Impede que o elemento seja comprimido quando o contêiner encolhe.

#22 flex-basis: 270px;

Determina o tamanho base inicial do item antes da distribuição de espaço restante.

#23 flex: 1 1 260px;

Shorthand combinando flex-grow, flex-shrink e flex-basis em uma única declaração.

#24 align-self: flex-end;

Permite que um item filho individual sobrescreva a regra align-items do pai.
